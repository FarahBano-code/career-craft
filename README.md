# AI Resume Builder

An AI-powered resume builder that helps users create professional and ATS-friendly resumes in minutes.

## Features

- AI-powered resume generation
- Professional resume formatting
- ATS-friendly resume structure
- Resume improvement using AI
- PDF download
- Clean and responsive interface
- FastAPI backend
- Groq AI integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI
- Pydantic

### AI
- Groq API
